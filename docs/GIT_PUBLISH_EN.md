# Git publishing — quick reference

1. Open `Versions & Git` and choose GitHub or GitLab.
2. Verify the Personal Access Token.
3. Select `ESP32 Project` or `Full Studio Source`.
4. Click `Scan before Git`.
5. Review Secret Scrubber statistics.
6. Choose Private/Public.
7. Enter repository name and commit message.
8. Publish.

Secret Scrubber never modifies local files; it sanitizes only the temporary cloud bundle.
