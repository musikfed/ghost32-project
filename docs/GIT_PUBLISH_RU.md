# Git publication — краткая памятка

1. `Versions & Git` → GitHub или GitLab.
2. Проверить Personal Access Token.
3. Выбрать `ESP32 Project` или `Full Studio Source`.
4. Нажать `Проверить перед Git`.
5. Проверить статистику Secret Scrubber.
6. Выбрать Private/Public.
7. Ввести repository и commit message.
8. Опубликовать.

Secret Scrubber не изменяет локальные файлы: он чистит только временный cloud bundle.
