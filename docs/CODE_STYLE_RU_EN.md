# Bilingual code comments / Двуязычные комментарии
Для новых и существенно изменённых мест используем пары:
```python
# EN: Keep LAN traffic out of environment proxies.
# RU: Не отправляем локальный LAN-трафик через proxy из переменных окружения.
```
Не комментируем очевидные строки; двуязычно объясняем архитектуру, безопасность, аппаратные ограничения и нетривиальное поведение.
